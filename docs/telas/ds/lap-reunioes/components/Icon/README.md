# Icon

Código: `apps/desktop/src/renderer/src/design/Icon.tsx`. Ícone `lucide-react` no padrão do app, decorativo para leitor de tela.

Medidas da densidade (feature `densidade`, 20/11/2026). Fonte da verdade: o componente e `design/tokens.css`; se divergir, vale o código. Exemplo renderizável em `preview.html` (claro e escuro).

## Medidas

| Medida | Valor |
|---|---|
| Tamanho | 16 (14 no `ActionButton`) |
| Traço | 1,5, pontas retas (`square`), cantos `miter` |
| Cor | `currentColor` |

## Variantes

| Variante | Como fica |
|---|---|
| 16 | padrão |
| 14 | botões compactos |
