# Shortcut

Código: `apps/desktop/src/renderer/src/design/Shortcut.tsx`. Dica de atalho dentro de um controle; o atalho é anunciado por `aria-keyshortcuts`.

Medidas da densidade (feature `densidade`, 20/11/2026). Fonte da verdade: o componente e `design/tokens.css`; se divergir, vale o código. Exemplo renderizável em `preview.html` (claro e escuro).

## Medidas

| Medida | Valor |
|---|---|
| Fonte | 12, peso 400, a família da interface |
| Opacidade | 0,8 sobre a cor do controle |

## Variantes

| Variante | Como fica |
|---|---|
| no botão | `⌘N` à direita do rótulo |
| na barra | `⌘⇧L` em "Bloquear", `⌘1`…`⌘9` nas abas de Configurações |
