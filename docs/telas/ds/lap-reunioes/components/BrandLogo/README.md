# BrandLogo

Código: `apps/desktop/src/renderer/src/design/BrandLogo.tsx`. Logo do app: o logo próprio escolhido em Configurações (PNG) ou, sem ele, o `LapSymbol`.

Medidas da densidade (feature `densidade`, 20/11/2026). Fonte da verdade: o componente e `design/tokens.css`; se divergir, vale o código. Exemplo renderizável em `preview.html` (claro e escuro).

## Medidas

| Medida | Valor |
|---|---|
| Tamanho | 28 × 28 por padrão |
| Imagem | `object-contain`, raio 4 |
| Sem logo próprio | `LapSymbol` |

## Variantes

| Variante | Como fica |
|---|---|
| com logo | a imagem escolhida |
| sem logo | o símbolo da LAP |
