# EmptyState

Código: `apps/desktop/src/renderer/src/design/EmptyState.tsx`. Estado vazio centralizado na área.

Medidas da densidade (feature `densidade`, 20/11/2026). Fonte da verdade: o componente e `design/tokens.css`; se divergir, vale o código. Exemplo renderizável em `preview.html` (claro e escuro).

## Medidas

| Medida | Valor |
|---|---|
| Ilustração | 20 abaixo (`mb-5`) |
| Título | 17/24, peso 600, `--title` |
| Texto | 13/20 `--text-muted`, 8 acima (`mt-2`), largura máxima 400 |
| Ação | 16 acima (`mt-4`) |

## Variantes

| Variante | Como fica |
|---|---|
| com ação | botão primário |
| sem ação | só ilustração, título e texto |
